# Geralt Voice 3.0.0-rc.2

**Персональный голос для твоих сообщений.** Поддержать, пошутить, пофлиртовать, ответить уверенно или привести в порядок рабочий текст — с сохранением твоей мысли и фактов.

[**Скачать ZIP навыка ↓**](Geralt%20Voice%203.0.0-rc.zip) · [**Инструкция GPT**](prompts/GPT.md) · [**Инструкция Claude**](prompts/CLAUDE.md) · [**Быстрый старт**](prompts/QUICK.md)

| 24 ситуативные роли | 108 авторских примеров | 64 проверочных заданий |
|---|---|---|
| Подача под конкретный разговор | Синтетические демонстрации голоса | Отдельный набор для проверки поведения |

## Начни за минуту

**GPT.** Открой [инструкцию GPT](prompts/GPT.md), скопируй её в поддерживаемое поле инструкций или задай как установку текущего чата. Затем пришли контекст и задачу.

**Claude.** Возьми [инструкцию Claude](prompts/CLAUDE.md) и добавь её туда, где твоя среда принимает инструкции. Для короткого знакомства с голосом есть [компактное ядро](prompts/QUICK.md).

**Среда с поддержкой навыков.** Скачай [Geralt Voice 3.0.0-rc.zip](Geralt%20Voice%203.0.0-rc.zip) и подключи его через механизм установки навыков своей среды. Внутри одна папка `geralt-voice/`: ядро, версия, метаданные и все справочники. Точная версия этого кандидата — **3.0.0-rc.2**; [архив с точным номером](dist/geralt-voice-3.0.0-rc.2.zip) содержит те же байты.

Загрузка ZIP в обычный чат сама по себе не устанавливает навык. Память и поддержка файловых инструкций зависят от продукта. Автономные инструкции GPT/Claude доступны отдельно по ссылкам выше.

## Как это звучит

![Настройки голоса: поддержка, дружеский подкол и спокойная граница](docs/assets/voice-controls.svg)

Подача регулируется независимо: теплота, юмор, напор, экспрессия, мат, близость, формальность, объём и глубина. В личном чате базовый формат — строчные и запятые; для рабочих текстов или по запросу — обычная пунктуация.

| Хочешь | Скажи |
|---|---|
| Тёплый ответ | «Ответь ей тепло, как с ПК, без флирта» |
| Удачнее пошутить | «Сделай подкол смешнее, поменяй саму идею» |
| Спокойную уверенность | «Коротко и твёрдо, без наезда» |
| Взаимный флирт | «Подхвати её шутку, мы взаимно флиртуем» |
| Бережную редактуру | «Только ошибки, мои слова не переставляй» |
| Полную переработку | «Перепиши полностью, сохрани смысл и неопределённость» |
| Рабочее сообщение | «Официально, с обычной пунктуацией» |

Есть дополнительные ориентиры подачи: Саня Кинг — бурный комический разгон, Йохан Либерт — спокойная точность, Аянокоджи — лаконичность. Это авторские настройки, не подлинные цитаты. Основой остаётся твой голос.

## Новое в rc.2

**Йохан Либерт:** точное наблюдение, содержательное несогласие, спокойный вопрос и граница без театральной угрозы. **Киётака Аянокоджи:** факты отдельно от гипотез, решение по цели, понятный следующий шаг и уверенность без ложных обещаний.

Добавлены 12 демонстраций и 16 отдельных проверочных заданий. В [бенчмарке](BENCHMARK.md) — 24 текста, написанных ассистентом в этой сессии, с разбором слабых мест. Это авторская проверка, не слепой тест. Научные ориентиры и ограничения их проверки вынесены в [источники](docs/SOURCES.md).

## Что изменилось после 2.2.0

- Самостоятельное ядро и справочники вместо наложения старых инструкций.
- Независимые настройки подачи, 24 роли и новый банк примеров.
- Сохранение смысла, отрицаний, неопределённости и обязательств при редактуре.
- Без механического стопа по числу сообщений и обязательного редакторского отчёта.
- Автономные экспорты GPT/Claude и воспроизводимая сборка ZIP.

Подробный [переход с 2.2.0](docs/MIGRATION.md). [Исторический архив 2.2.0](geraltvoice2.2.0.zip) сохранён; одновременно подключать старую и новую инструкции не нужно.

## Статус выпуска

**Кандидат выпуска.** Автоматические проверки проверяют структуру, данные, экспорты и упаковку. Поведенческие пробы описаны в [отчёте](evaluation/RESULTS.md); границы выводов — в [BENCHMARK.md](BENCHMARK.md). Межпровайдерный A/B GPT и Claude не выполнен. Числа примеров и заданий обозначают покрытие сценариев, а не процент качества; незаметность помощи и симпатия собеседника не гарантируются.

## Разработка

Python 3.10+ и зависимости из [requirements-dev.txt](requirements-dev.txt).

```bash
python3 -m pip install -r requirements-dev.txt
python3 scripts/build.py
python3 scripts/check.py --archive
python3 -m unittest discover -s tests -v
```

Исходники — SKILL.md, справочники, examples.jsonl и roles.json. Банк Markdown, таблица ролей, prompts, release.json и ZIP генерируются. Сборка воспроизводима; [SHA256SUMS](dist/SHA256SUMS) позволяет проверить архив.

Старые ZIP в корне сохранены. Исторические проценты бенчмарка 2.2.0 были оценкой предписаний правил, а не модельных выходов. Приватные логи и сведения о собеседниках в новый публичный пакет не включены.
