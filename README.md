# .ClaudeMD

`geralt-voice` это навык для Claude, который отвечает за всё, что Геральт отправляет от своего имени: переписку с друзьями и девушками, споры про аниме, РП-жалобы и юридические тексты. Он делает три работы сразу: понимает, что на самом деле просят, читает состояние собеседника и выдаёт текст, который звучит как живой человек, а не как ИИ. Часть правил выведена из замеров по реальным перепискам, и при конфликте с теорией побеждают именно они.

**Актуальная версия 1.1.1 от 9 августа 2026.** Нумерация перезапущена с переездом навыка из zip-архива в репозиторий: объяснение и старая шкала 1.0 – 4.0 лежат в `geralt-voice/CHANGELOG.md`.

## Что внутри

Навык распакован файлами в `geralt-voice/`: `SKILL.md` грузится всегда, одиннадцать файлов в `references/` подключаются по делу. Дорелизный архив 4.0 лежит в корне как `geralt-voice-v2.zip` и не трогается: он остаётся точкой отката, которую можно открыть без git-команд.

| Файл | За что отвечает |
|---|---|
| `SKILL.md` | четыре цикла работы, разбор живого случая по шагам, указатели на остальное |
| `references/input.md` | разбор входа, семь типов кусков в сообщении, счётчик очереди, карта его ошибок |
| `references/commands.md` | как он ставит задачу: слитный текст, позиция команды, пять осей, реестр |
| `references/modes.md` | шесть режимов, три степени огранки, бюджет правки, шкала объёма |
| `references/registers.md` | пять ступеней формальности, четыре температуры, доза мата |
| `references/syntax.md` | склейка и разрыв фразы, замена тире, ритм длин, границы сообщений |
| `references/voice.md` | лексикон, приёмы, юмор, что делает текст живым |
| `references/anti-ai.md` | маркеры текста и поведения |
| `references/live-calibration.md` | замеры по живым перепискам, профили, журнал правок |
| `references/stop.md` | красные линии, единственное место, где правильный ход не выдавать текст |
| `references/examples.md` | 29 пар «вход, правильный выход», он же регрессионный набор |
| `references/self-check.md` | обязательный прогон из семи пунктов и ветки по типам текста |
| `scripts/check.py` | структурная проверка навыка, девять тестов, запускается перед релизом |

## Как развивался

**1.0.0.** Закрыта главная дыра предыдущей шкалы: в навыке не было ни одного правила про строение фразы. Шесть мест толкали резать предложение и ни одного не склеивало, поэтому причина отрывалась от следствия. Появился `syntax.md`, производство разделилось на два прохода, пришли три степени огранки с измеримым бюджетом, дельта-отчёт и регрессионный набор.

**1.0.1.** Разобран механизм команд, который держался на одной строке. Появился `commands.md` и шестой режим, вставка.

**1.0.2.** Починен дефект, внесённый в 1.0.1: реестр команд стал ускорителем, а не перечнем разрешённого, добавлен предохранитель «при сомнении это текст».

**1.0.3.** Файл команд пересобран под то, как он пишет на самом деле: слитный текст вперёд, скобки вниз как частный случай, позиция команды свободна. Добавлены ограничитель охвата, отчёт о состоянии переписки, заготовка смысла и следующий ход как отдельная задача.

**1.1.1.** Проверки перестали быть ручными: появился `scripts/check.py` на девять структурных тестов. Первый же запуск нашёл два файла без оглавления и продублированное правило.

**1.1.0.** Первый MINOR: скобка-вопрос вместо приказа, размещение элемента как отдельная задача, запрет самодиагноза, переопределение оформления по его прямому указанию. В шапку вынесен приоритет выше всех файлов: его прямое указание бьёт любое правило навыка.

**Две версии одновременно запустить нельзя,** поэтому это не A/B на живых ответах. Это **прогон правил**: берётся вход, определяется, что предписывает каждая версия, и фиксируется расхождение. Настоящий замер появится только после недели работы.

## Внутренние тесты

С версии 1.1.1 они автоматические: `python3 geralt-voice/scripts/check.py`, девять проверок, код возврата 1 при ошибке.

```
ФАКТЫ
  версия: SKILL.md 1.1.1, CHANGELOG 1.1.1, README 1.1.1
  пар в банке: 29
  пунктов в блоках чеклиста: 47
  SKILL.md: 299 строк (грузится всегда)
  всего строк в навыке: 2787
  пары по логам: 21, по правилам: 8 (72% живых)

ВСЁ СОШЛОСЬ. Предупреждений 0, ошибок нет
```

До этого проверки гонялись руками, и поэтому сбитая нумерация пар прожила три версии незамеченной.

**Скрипт проверен на поломках, а не только на исправном навыке.** В шесть файлов по очереди вносилась ошибка, и каждый раз проверялось, что возврат равен 1 и в выводе названа именно та ошибка: рассинхрон версии, сбитая нумерация пар, ссылка на несуществующий файл, длинное тире, пропавший обязательный раздел, ссылка на несуществующий раздел. Шесть из шести пойманы, после отката всё вернулось в зелёное.

## Известные риски

**Риск из 1.0.3 остаётся:** команда, разрешённая в начале сообщения, повышает шанс съесть первый кусок текста. Держит предохранитель «при сомнении это текст».

**Новый риск 1.1.0:** правило «его прямое указание бьёт любое правило навыка» снимает защиту в обе стороны. Если он попросит что-то, что по замерам не работает, навык это исполнит и скажет о риске одной строкой, но исполнит. Это сознательный размен: решает он.
