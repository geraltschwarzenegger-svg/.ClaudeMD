# Geralt Voice 3.0.0-rc.1

Персональный голос для сообщений от имени Геральта: разговорная ясность, поддержка, милота, флирт, юмор, кринж, дружеский разнос, спокойная жёсткость и рабочая речь.

Глобальная переработка 2.2.0: самостоятельное ядро, 24 ситуативные роли, 96 авторских примеров и 48 отдельных проверочных заданий. Личный чат по умолчанию — как с ПК: строчные и запятые. Подача и пунктуация переопределяются текущим запросом.

Статус — кандидат выпуска. Структура и сборка проверяются автоматически; выполненные поведенческие пробы описаны в [BENCHMARK.md](BENCHMARK.md). Межпровайдерный A/B GPT и Claude не выполнен. Незаметность помощи и симпатия собеседника не гарантируются.

## Начать пользоваться

| Среда | Что взять |
|---|---|
| Чат с GPT | [Инструкция GPT](prompts/GPT.md), применить в поддерживаемой среде инструкций или текущем чате |
| Чат с Claude | [Инструкция Claude](prompts/CLAUDE.md), применить там, где принимаются инструкции |
| Быстрая настройка | [Компактное ядро](prompts/QUICK.md) |
| Поддержка навыков | [ZIP навыка](dist/geralt-voice-3.0.0-rc.1.zip) или [папка навыка](geralt-voice/SKILL.md) |
| Работа с исходниками | [AGENTS.md](AGENTS.md) и [CLAUDE.md](CLAUDE.md) |

Произвольная загрузка ZIP в обычный чат не означает установку навыка. Возможности проектов, памяти и файловых инструкций зависят от продукта. Этот выпуск не устанавливает пакет в личную директорию навыков ChatGPT автоматически.

## Примеры запросов

- Ответь ей тепло, как с ПК, без флирта.
- Сделай подкол смешнее, поменяй саму идею.
- Саня Кинг, бурный комический разнос с матом.
- Йохан Либерт, спокойно и точно, без пафоса.
- Аянокоджи, коротко и уверенно.
- Мы взаимно флиртуем, подхвати её шутку.
- Только ошибки, мои слова не переставляй.
- Перепиши полностью, сохрани смысл и неопределённость.
- Официально, с обычной пунктуацией.

Именные ориентиры — авторские настройки подачи, не подлинные цитаты. Голос пользователя остаётся базой. Уверенность, теплота, мат и экспрессия регулируются отдельно.

## Разработка

Python 3.10+ и зависимости из [requirements-dev.txt](requirements-dev.txt).

```bash
python3 -m pip install -r requirements-dev.txt
python3 scripts/build.py
python3 scripts/check.py --archive
python3 -m unittest discover -s tests -v
```

Исходники — SKILL.md, справочники, examples.jsonl и roles.json. Банк Markdown, таблица ролей, prompts, release.json и ZIP генерируются. Сборка воспроизводима; [SHA256SUMS](dist/SHA256SUMS) позволяет проверить архив.

Старые ZIP в корне сохранены. Исторические проценты бенчмарка 2.2.0 были оценкой предписаний правил, а не модельных выходов. Приватные логи и сведения о собеседниках в новый публичный пакет не включены.
