# .ClaudeMD

raivetsu-comms это навык для Claude, который отвечает за всё, что Геральт отправляет от своего имени: переписку с друзьями и девушками, споры про аниме, РП-жалобы и юридические тексты. Он держит пять регистров его речи, чёрный список ИИ-маркеров, чтение состояния собеседника, юмор, защиту от агрессии и романтическую стратегию. Тринадцать файлов, часть правил выведена из исследований, часть из замеров по живым перепискам.
