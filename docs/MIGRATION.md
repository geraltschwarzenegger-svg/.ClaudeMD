# Переход с 2.2.0

Старые архивы остаются историческими. Новая папка geralt-voice — самостоятельная переработка, а не наложение новых запретов на прежний стек. Не загружать обе инструкции одновременно: у них разные приоритеты и правила формата.

| Старый материал | Новый маршрут |
|---|---|
| input.md и commands.md | Ядро и editing.md |
| modes.md | Операции в editing.md; длина и глубина по конкретному заказу |
| registers.md | Независимые настройки в ядре и voice-profile.md |
| syntax.md и anti-ai.md | Предпочтение формата без заявления о детекторе ИИ |
| voice.md | conversation.md, humor-conflict.md и роли |
| depth.md | Новая версия depth.md без механического лимита мыслей |
| live-calibration.md | Обобщённый профиль; частные контакты не включаются в публичную поставку |
| stop.md | Контекст, известные границы и отдельная помощь при опасности; стопа по трём сообщениям нет |
| self-check.md | Краткая проверка смысла, уместности и поручения |
| examples.md | Новый синтетический банк с явным происхождением |
| scripts/check.py | Репозиторный валидатор и негативные тесты |

Для личного чата базовый формат теперь явно соответствует неоднократному пожеланию пользователя: строчные и запятые. Официальные тексты и явные настройки имеют свой формат. Не переносить роль, мат и близость из предыдущего заказа автоматически.

Редактура не использует обязательный процент сохранённых слов. Защищаются смысл, отрицания, условия, неопределённость и обязательства. Полная переработка разрешена по запросу даже при наличии черновика.

Тексты GPT и Claude генерируются из общих источников. Копия файла сама по себе не даёт долговременной памяти; следовать возможностям выбранной среды. ZIP содержит одну папку навыка с VERSION и необходимыми справочниками. Тестовые задания и сырые пробы в устанавливаемый пакет не входят.
