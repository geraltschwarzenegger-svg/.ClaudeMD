# Источники и границы выводов

Проверено 27.10.2026. Ниже краткие пересказы и инженерные решения, а не рецепты гарантированного влияния на человека.

| Источник | Что можно использовать | Чего источник не доказывает |
|---|---|---|

| [Anthropic: Prompting best practices](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices) | Разнообразные примеры, понятные границы данных и инструкций | Что XML сам создаёт естественную речь |
| [Anthropic: Context engineering](https://www.anthropic.com/research/effective-context-engineering-for-ai-agents) | Небольшой полезный контекст и разумная детализация | Что число строк измеряет реальную стоимость |
| [OpenAI: Evaluation best practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices) | Конкретные критерии, разные случаи, попарные оценки с проверкой смещений | Достаточность самооценки модели |
| [Huang et al., 2017](https://pubmed.ncbi.nlm.nih.gov/28447835/) | Вопросы по ходу разговора могут выражать внимание; исследованы связи с симпатией | Гарантию свидания и пользу допроса |
| [Kluger & Malloy, 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6857721/) | Учитывать методологическую критику анализа speed dating | Что все исходные результаты опровергнуты |
| [Yeomans et al., 2019](https://pubmed.ncbi.nlm.nih.gov/31714109/) | Ответ авторов на критику; не сводить дискуссию к одному лозунгу | Что спор оправдывает точные универсальные квоты вопросов |
| [Ireland et al., 2011](https://pubmed.ncbi.nlm.nih.gov/21149854/) | Сходство речевых стилей изучалось как предиктор отношений | Причинный эффект намеренного копирования каждого слова |
| [Gable et al., 2004](https://pubmed.ncbi.nlm.nih.gov/15301629/) | Активный доброжелательный отклик на хорошие новости заслуживает внимания | Что восторг нужен на каждую мелочь |
| [Crasta et al., 2021](https://pubmed.ncbi.nlm.nih.gov/33600200/) | Измерять восприятие участия и нечуткости | Запрет конкретных русских слов и фраз |

| [Codex: AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md) | Инструкции файлового агента в поддерживаемой среде | Автоматическую установку ZIP в обычный чат |
| [Claude Code: memory](https://code.claude.com/docs/en/memory) | Проектные инструкции CLAUDE.md и поддерживаемые механизмы | Работу файла во всех продуктах Claude |

Приёмы юмора, роли и три именных профиля — авторские проектные решения. Их точное сходство с речью стримера или художественных персонажей не измерялось. Приватные чаты не публикуются; профиль содержит обобщённые предпочтения, а банк примеров создан для этого выпуска.
