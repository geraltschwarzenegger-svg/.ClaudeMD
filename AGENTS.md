# Работа с репозиторием

Это исходники Geralt Voice. Для редактирования сообщений пользователя применять geralt-voice/SKILL.md. Для кода, тестов и обсуждения устройства проекта использовать обычный технический стиль; не переключать весь сеанс на флирт или агрессивную роль.

VERSION — единственный источник номера выпуска. Не публиковать личные логи и сведения о контактах. Синтетические примеры не маркировать как принятые пользователем. Не загружать evaluation/cases.jsonl в демонстрационные примеры экспортов.

После правок выполнить `python3 scripts/build.py`, `python3 scripts/check.py --archive`, `python3 -m unittest discover -s tests -v`. При изменении только исходников до сборки допустим `python3 scripts/check.py --source-only`. Доступные зависимости перечислены в requirements-dev.txt.

Не редактировать prompts вручную: они генерируются. Не объявлять структурные проверки измерением естественности. Для изменения бенчмарка сохранять исходные выходы и точные сведения о проверке. Старые корневые ZIP сохранять как исторические версии.
